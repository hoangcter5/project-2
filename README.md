# DashStack

Hệ thống quản trị dashboard theo spec (Admin AD-ADM01–15 + User USR-*).

## Chạy

```bash
npm install
npm run dev
```

http://localhost:5173

## Tài khoản demo

- Admin: `admin@dashstack.dev` / `Admin@123` → `/admin`
- User: `user@dashstack.dev` / `User@123` → `/app`
- Đăng ký mới: `/register` (USR-REG01)

Dữ liệu lưu localStorage (`dashstack.spec.v1`).
